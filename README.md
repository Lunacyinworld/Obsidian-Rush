# Obsidian Rush
Shooter de arena 1v1: modo Normal (IA) y Competitivo (ligas Bronce a Obsidiana).

    npm install
    npm start
Abre http://localhost:3000 en dos navegadores y pulsa "Buscar partida" en ambos para probar el modo competitivo.

Variables: PORT (puerto) y DATA_DIR (carpeta donde se guarda data.json con los perfiles).
Aviso: en hosting gratis el disco se borra al redesplegar; para ligas permanentes usa un disco persistente o una base de datos.
